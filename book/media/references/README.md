# Reference images (from S-11)

Collected 2026-11-10 while sourcing the PD plates (`plans/registry/pd-sources.md`). **None of these is printed.** They are period references for GEN plates: to look at, to attach to a chat model as a style reference, or (where the last column allows) to use as input for an image edit. Large sheets are downscaled; the source page has the full file.

**Use column.**
- **edit OK**: public domain or CC0, so it may be fed to a generator or edited into a printed plate. Credit the source in the plate's `.yaml`.
- **look only**: a BnF scan. Free for non-commercial use, so fine for viewing and checking period details. Do not use it as edit input or crop it into a printed plate: that is commercial reuse, and it needs a BnF licence (S-11 decided not to buy one). For a free version of an LdM miniature, use Omont's 1907 facsimile.
