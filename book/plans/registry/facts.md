# Fact verification sheet (S-06)

_2026-11-03. Output of [S-06](../spikes/S-06-fact-verification.md); first draft per S-14's 25-claim list. No web research in this pass: each claim was read against Yule–Cordier in `refs/`, the bibliography, the gazetteer, the media files, and the two graded people runs (`research/results/CHR-people-intake.md`, run 1, leads only; `CHR-people-2-intake.md`, run 2, checked)._

**Verdicts.** *confirmed*: the claim holds against a seen source. *corrected*: the claim is wrong or misattributed; the value column gives the right one. *still open*: no seen source; the chapter uses the **Hedge** wording until a library check settles it (list in S-06 *Findings*). "in part" splits a claim: the value column says which half is which.

**Sources.** Keys are from `bibliography.bib`. `yc` is Yule–Cordier 1903 (Cordier's bracketed additions included); `ycadd` is Cordier's 1920 *Addenda*. The `refs/…:line` pointers are for checking here; Notes cite by Book and chapter (S-24), never by these lines. "reported" means another work's account of a source we have not seen. A claim with no source at all is marked **unconfirmed**.

**Rule for chapters.** State a *confirmed* or *corrected* value plainly. Use a *still open* claim only in its hedge. The `.T1` task of each file listed applies this sheet.
