# BLD — Build and tooling

**Status:** backlog · **Plan docs:** `content-revision-plan.md` § W0; `multimedia-plan.md` § Toolchain

## Scope
Everything that turns the Markdown repo into checked and typeset output: lint, LaTeX build, media generation scripts, commit hooks.

## Backlog
- Toolchain installed 2026-11-10: pandoc, LuaLaTeX, biber, biblatex-chicago, Noto fonts (S-08, Debian packages); matplotlib + cartopy in `tools/media/.venv` (S-09).
- Seed scripts in `tools/seed/` (overlap, stats, Ramusio brackets). Superseded by `tools/lint.py` + `tools/yule.py` (S-02). The seed `ramusio-brackets.txt` is now regenerated by `python3 tools/yule.py --ramusio`.
- Lint runtime: ~2 s for all 49 files, about 1 s for a single file (loading the Yule n-grams dominates); fast enough for a pre-commit hook.
- Print build done in S-08: `tools/build/build.sh` + `book.lua` (vector swap, per-chapter endnotes, markers, tables, media checks) + `book.latex` (6×9 in, Noto Serif, biblatex-chicago). Conventions: `plans/registry/markdown-conventions.md`.
