# Archive

- [Proposed voice](proposed-voice/) preserves chapter drafts, prompts, and comparison notes from the voice rollout.
- [Artwork](artwork/) preserves plate variants and retired legacy art. The [credits](../manuscript/assets/ATTRIBUTIONS.md) identify the material used by the current edition.
- [Editorial records](editorial/) preserve completed critique and audit snapshots.
- [Seed tooling](tools/seed/) records the early import and rewrite analysis.

For new work, use the [manuscript](../manuscript/), [research](../research/), and [materials](../materials/) folders. The build reads the ordered manuscript and its placed artwork. Local generated proofs belong in the ignored `build/` directory.
