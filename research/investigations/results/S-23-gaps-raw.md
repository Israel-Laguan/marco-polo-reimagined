Research reference for a three-volume illustrated retelling of Marco Polo's book (events c. 1260–1295), compiled from seven research-notes files (A1–A5, B1–B4, C1–C5). This document is a working reference, not a narrative report: consult it plate by plate. ## 0. TOP-LEVEL CAVEAT — systemic tooling limitation (read before using anything below)

**Every one of the seven research passes independently hit the same wall: this session's web-access tooling cannot view images.** WebFetch converts a page to text/markdown and summarizes it; it does not render pixel content. Direct attempts to pull image files straight from institutional CDNs/IIIF servers (`images.metmuseum.org`, `asia.si.edu`, Hermitage, Edinburgh's Luna viewer, Smithsonian IIIF manifests) were blocked by the environment's outbound proxy (403s, `robots_disallowed`). A Chrome browser extension was attempted at least twice (A2, A5) specifically to get a real screenshot/view, but the extension was not connected in this session.

**Practical consequence:** even where a genuine institutional record page was opened and its title/date/accession line verbatim-quoted — satisfying Rules 1, 2 and 5 — Rule 3 ("image viewed") could almost never be honestly satisfied for any *new* object this pass. This is why the ledger below is dominated by "partly" rather than "passed." It is a **tooling limitation, not a research-effort failure** — every notes file documents real, extensive search and record-opening work.

**Action required before any plate is painted:** a follow-up pass with genuine image-viewing capability (a connected Chrome extension, a working screenshot/vision tool, or an environment whose proxy allows fetching institutional image/IIIF servers) is needed before any "partly" item below can be upgraded to "passed." Treat every "not viewed" cell in the tables as exactly that — a verified citation with a pin in the map, not yet a picture anyone has looked at.
